# Stable Fusion — AI Art Generator

Local AI art generation pipeline: Stable Diffusion 1.5 prompts → image generation → gallery + CrowPanel P4 display.

## How it works

1. **Cron job** runs every 30 minutes
2. `art_generator.py` picks a random creative prompt
3. Generates image via SD 1.5 (diffusers + CUDA, RTX 3060)
4. Adds "Generated by Local AI" watermark
5. Saves to `~/.hermes/gallery/`
6. Converts to RGB565 for the CrowPanel P4 ESP32 display
7. Cleans up images older than 24 hours

## Files

| File | Purpose |
|------|---------|
| `art_generator.py` | Main generator — prompt, SD 1.5 inference, watermark, gallery mgmt |
| `convert_to_raw.py` | Converts PNG → RGB565 raw format for P4 panel |
| `gallery_server.py` | HTTP gallery server for browsing generated art |
| `gallery_watchdog.py` | Watches gallery dir and serves latest image |
| `build_p4_art.bat` | Builds the P4 art frame firmware |
| `gallery.html` | Web gallery template |
